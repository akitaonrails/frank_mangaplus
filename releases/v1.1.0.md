# FRANK MANGA+ v1.1.0

Feature release: content-language selection across the nine MANGA Plus catalogs, and a chapter list that surfaces what you haven't read yet.

## Content languages

- A picker in the header selects any combination of the nine catalogs — EN, ESP, FRA, IND, PT-BR, RUS, THA, VIE, DEU. The selection drives Search, Library, title detail, and the reader, persists across sessions (`mp:contentLanguages`), and never empties: the last active language can't be switched off.
- Search fetches the selected catalogs and merges them in fixed header order, so editions of the same work (MANGA Plus issues a separate titleId per translation) sit side by side. Library filters the same way: other editions of a favorite are hidden, not removed, and reappear when their language is re-selected. Non-English covers carry a language badge.
- The `Title.language` wire-enum map was inferred and three values were wrong (ind/ptb/rus sat on each other's numbers). Corrected and now pinned two ways: recorded protobuf fixtures for all nine catalogs, and agreement with the official app's own proto. Enum 8 is ITALIAN there; no Italian catalog exists, so it stays unmapped.
- Outbound `lang`/`clang` are clamped to the supported set (case-insensitive, English default) instead of reaching the API verbatim, and `title_detail`/`manga_viewer` responses are validated against the requested edition — a mismatch is an error, not a silent substitution, so chapter navigation can't wander into another translation.
- The Rust catalog/cache paths now filter by `clang` (catalog language) instead of `lang` (interface language). Caches written by older builds with the wrong filter are evicted and refetched instead of serving an empty catalog for the rest of the TTL.

## Hide read chapters

- A title's chapter list now hides read chapters by default — opening a long-running series shows what's left to read instead of everything ever published. A toggle next to the sort button cycles **unread only → read collapsed → all chapters** and persists (`mp:readVis`). When everything is read, a "Show all chapters" escape hatch appears so the list can never strand you.
- Rows are no longer uniform height (a collapsed read row is a slim line), so the virtualizer binary-searches a prefix-sum height table instead of dividing by a constant.
