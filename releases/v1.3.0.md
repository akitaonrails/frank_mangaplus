# FRANK MANGA+ v1.3.0

Manual pairing corrections for chapters whose spreads are not marked by the
MANGA Plus API.

## Fix unmarked double-page spreads per chapter (#13, closes #12)

Double-page mode still follows authoritative RIGHT/LEFT spread markers
automatically. When a chapter has no markers, you can now press `P` or click
the pairing-shift icon at a wrongly paired frame to shift pairing from that
point. Page 1 toggles the cover rule; a later selected page becomes solo and
the following pages resume with the opposite pairing.

- A correction on page 1 switches between a solo cover and pairing from the
  first page.
- Later corrections handle chapters whose spread parity changes partway
  through, including chapters that need more than one adjustment.
- Corrections persist per chapter across sessions.
- Removing a correction also clears later corrections whose parity depended
  on it.
- Chapters with API-marked spreads keep automatic grouping and ignore stale
  manual corrections.

The help dialog documents the new shortcut, and the spread-pairing audit now
records fresh live-API evidence for English and Brazilian Portuguese editions
(#11).

## Security hardening

- Device secrets are written atomically and restricted to the current user on
  Unix (`0700` config directory, `0600` secret file). Existing permissive files
  are hardened when read, symlink targets are rejected, and credentials never
  fall back to a shared temporary directory.
- `rustls` is updated to 0.23.45, resolving RUSTSEC-2026-0285.
- Every GitHub Action is pinned to an immutable, verified commit. Release jobs
  use least-privilege token permissions and validate release tags before using
  them in shell commands.

## Tests + verification

- Reader grouping and persistence tests cover initial and later shifts,
  multiple corrections, removal dependencies, chapter boundaries, malformed
  stored data, and protection for API-marked chapters. 175 Vitest tests total.
- Backend tests cover private secret-file permissions, migration, atomic
  replacement, missing persistent config, and symlink rejection.
- `./verify.sh` on merged `main`: all green — Rust tests/clippy, Vitest,
  `svelte-check`, production build, and Vite dev CSS probes.
- GitHub CI is green on Ubuntu, macOS, and Windows.
