# FRANK MANGA+ v1.3.1

This patch release keeps your reading position stable when the app window
changes size and refreshes compatible dependencies.

## Keep reading position across window resizes (#17)

Resizing the window, docking or undocking a laptop, or otherwise changing the
display geometry no longer moves the reader to a different page. The reader
anchors the first visible page for the entire resize burst and restores it
after layout settles, without saving transient pages as reading progress.

Pending restoration is cancelled when the reader changes chapters or unmounts,
so a resize from the previous chapter cannot affect newly loaded pages.

## Dependency and security maintenance

- Compatible Tauri, Svelte, Vite, and TypeScript definition updates are
  included without adopting breaking framework major versions.
- CI and release workflows use the Node 24-based `actions/checkout` and
  `actions/cache` releases, pinned to verified immutable commits.
- The Rust dependency graph updates `quinn-proto` and `rustls`, resolving the
  published advisories present in v1.3.0.
- The exact `wreq` and `wreq-util` versions required for the MANGA Plus CDN TLS
  fingerprint remain pinned and were verified with a live authenticated API
  registration/profile smoke test.

## Tests and verification

- New regression tests cover resize bursts, inactive readers, and cancellation
  during reader-state reset. 178 Vitest tests total.
- A browser-level smoke test verified that page 4 remains page 4 after a resize
  and after a rapid resize burst.
- `./verify.sh` is green: Rust tests and Clippy, Vitest, `svelte-check`, the
  production frontend build, and Vite development CSS probes.
- GitHub CI is green on Ubuntu, macOS, and Windows for the audited changes.
