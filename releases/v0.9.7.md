# FRANK MANGA+ v0.9.7

Reader immersion release: the page now owns the whole window, with auto-hiding bars.

## Auto-hiding reader bars

- The reader header and footer collapse 2 seconds after opening a chapter, and again 2 seconds after the mouse leaves them.
- Both bars are now fixed overlays that slide in/out over the page, so pages render at the full window height instead of subtracting the bar heights.
- Moving the mouse to the very top edge of the window slides the header back in; the very bottom edge brings back the footer/progress bar.
- Edge detection uses a window `mousemove` listener rather than invisible hover strips, so page-turn clicks near the edges are never swallowed.
- While the pointer is over a bar it stays open indefinitely; the hide countdown only arms once the pointer leaves.

## Dependency updates

- Frontend (within semver): Svelte 5.56.10, SvelteKit 2.70.3, svelte-check 4.7.6, Vite 6.4.3, Vitest 4.1.11, @tauri-apps/api 2.11.1, @tauri-apps/cli 2.11.4, @types/node 25.9.5.
- Major bumps deliberately deferred: Vite 8, TypeScript 7, vite-plugin-svelte 7 — separate migration work.
- Rust: routine `cargo update` of transitive deps (tauri patch releases, tokio, serde, etc.).
- **`wreq`/`wreq-util` are now pinned exactly** (`=6.0.0-rc.28` / `=3.0.0-rc.11`): wreq 6.0.0-rc.31 swapped its BoringSSL backend (boring2) for btls, which changes the TLS fingerprint. The MANGA Plus CDN accepts specifically the Android OkHttp BoringSSL profile, and fixture tests can't catch a live handshake regression, so the backend swap is held back until it can be verified against the live CDN.

## Tests + verification
